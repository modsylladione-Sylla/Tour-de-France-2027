\# 🚴 Tour de France 2027 - Optimisation des étapes



\## 📋 Description

Projet d'optimisation des étapes du Tour de France 2027 en utilisant :

\- \*\*KMeans / CAH\*\* pour le regroupement des villages en 21 étapes

\- \*\*Algorithme glouton\*\* + \*\*2-opt\*\* pour l'optimisation des parcours

\- \*\*Visualisation\*\* des étapes sur une carte de France



\## 📊 Résultats

\- \*\*21 étapes\*\* optimisées

\- \*\*\~4 100 km\*\* de parcours total

\- \*\*Étape reine\*\* : 280 km

\- \*\*Étape la plus courte\*\* : 195 km



\## 🔧 Technologies

\- Python 3.10+

\- Pandas, NumPy

\- Scikit-learn (KMeans, AgglomerativeClustering)

\- Matplotlib
